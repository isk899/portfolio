The Ancient Empires

A real-time strategy game in the spirit of Age of Empires 1 — three civilisations, two ages, five resources, procedurally generated maps and up to three bot opponents at three difficulty levels. It opens from one file and starts playing.

The hard part was never the drawing. Grid pathfinding makes units walk in staircases, so after A* returns a route I walk it backwards and delete every waypoint already visible from the one before it — what survives is a straight line wherever a straight line was possible. On top of that each enemy unit runs its own finite state machine, and the whole thing has to stay inside one file with nothing to install.

Oh La Vache Salon

A booking page built for a working American salon on their own services, prices and stylists. Not a mockup — the whole flow runs, right down to the confirmation.

Every salon site in the world opens with a service list. Their reviews are all about people — clients follow one stylist for years — so this page opens with the seven faces instead, and the booking panel scopes itself to whoever you picked. Slots are generated from the salon's real opening hours.

Editorial page · scroll-driven

Pagani Huayra Roadster

A long-form page about a roadster that came out lighter than the coupe it was cut from — 1,280 kg dry, 764 hp, a Carbo-Titanium monocoque.

Three sections are horizontal while the page itself only ever scrolls down. Each one is a tall track with a sticky viewport pinned inside it; vertical progress through the track is measured and fed straight into a horizontal transform, so the reader keeps doing the one gesture they already know.

Porsche 911 Turbo S

A typography-led page for a car that doesn't need help selling itself — built to find out how far layout and type alone could carry a product page.

Images are the entire page here, so one missing file is fatal. Every photo tries a local copy, then a CDN copy, then falls back to a painted panel in the same palette. The hero never shows a hole, whatever the network is doing that day.

Telegram bot · Python

Media downloader bot

Send it a link, get the video back without a watermark — TikTok, YouTube and Instagram, in private chats and inside groups. It has live users.

The TikTok CDN is blocked by my ISP, so the bot simply cannot reach it from here. Requests bound for that CDN leave through a local SOCKS5 proxy while everything else takes the direct route — two network paths inside one process, chosen per request.
